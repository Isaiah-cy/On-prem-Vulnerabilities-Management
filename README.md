# Vulnerability Management Lifecycle — ISO 27001

## 📌 Project Overview

This project demonstrates an end-to-end **Vulnerability Management Lifecycle** aligned with **ISO/IEC 27001:2022 Annex A Control 8.8 — Management of Technical Vulnerabilities**.

The project applies a structured, evidence-based process for identifying, assessing, prioritizing, treating, and documenting technical vulnerabilities across an organization's IT environment.

## 🎯 Objective

The project was designed to demonstrate practical vulnerability management and ISO 27001 compliance capabilities through an eight-phase workflow:

* Asset register creation
* Asset configuration verification
* Vulnerability identification using **Tenable Nessus**
* CVSS-based vulnerability assessment
* Cybersecurity risk register development
* Risk matrix and heat map generation
* Risk treatment planning
* Record keeping and internal audit preparation

## 🔍 Vulnerability Assessment

Five vulnerabilities were identified during the Nessus vulnerability assessment.

Each vulnerability was evaluated using its **CVSS vector**, with the resulting Impact and Exploitability metrics used to determine risk scores and risk ratings.

The assessed vulnerabilities were documented in a structured **Cybersecurity Risk Register**, including:

* CVSS scores
* Risk ratings
* Affected assets
* Risk treatment decisions
* Remediation considerations

## 📊 Risk Management

A **5×5 risk matrix / heat map** was developed to visualize the distribution of identified risks based on **likelihood and impact**.

The resulting evidence chain connects:

**Asset → Vulnerability → CVSS → Risk Score → Risk Rating → Treatment → Evidence**
